## Иерархия классов

### 1. `BaseDevice` — абстрактный класс
**Ответственность:** общее состояние и поведение для всех умных устройств.

**Поля (private):**
- `_lastId` — статический счётчик ID;
- `Id`, `Name`, `Power`, `RoomName` — свойства (properties).
- `IsOn`, `IsBroken` — свойства с `protected set`.

**Методы:**
- `abstract string GetDeviceType()` — чисто виртуальный аналог.
- `virtual string Describe()` — может быть переопределён.
- `override bool Equals(object obj)` и `override int GetHashCode()` — сравнение по содержимому (имя и мощность).

### 2. `SmartLamp` — наследник
**Ответственность:** умная лампа с яркостью.

**Переопределяет:**
- `GetDeviceType()` — возвращает `"Умная лампа"`;
- `Describe()` — вызывает `base.Describe()` и дополняет яркостью.

**Копирование:**
- `ShallowCopy()` — через `MemberwiseClone()`;
- `DeepCopy()` — через вызов конструктора (независимая копия).

### 3. `SmartThermostat` — наследник (`sealed`)
**Ответственность:** термостат с целевой температурой.

**Переопределяет:**
- `GetDeviceType()` — возвращает `"Термостат"`;
- `Describe()` — полностью заменяет описание, **не вызывая** `base.Describe()`.

`sealed` запрещает дальнейшее наследование.

## Проверяемые правила предметной области

1. **Нельзя включить сломанное устройство** — проверка в `BaseDevice.TurnOn()`.
2. **Яркость лампы от 0 до 100** — проверка в `SmartLamp.SetBrightness()`.
3. **Температура от 5 до 30 °C** — проверка в `SmartThermostat.SetTargetTemp()`.

## Что демонстрирует `Program.cs`

1. **Порядок конструкторов:** сначала `BaseDevice()`, затем `SmartLamp()`.
2. **Полиморфизм:** массив `BaseDevice[]` хранит разные наследники; у каждого вызывается свой `Describe()`.
3. **Копирование:**
   - `ShallowCopy()` (`MemberwiseClone`) — копирует ссылки, оригинал меняется;
   - `DeepCopy()` (через конструктор) — оригинал не меняется.
4. **Equals / GetHashCode:** две разные лампы с одинаковыми параметрами равны по содержимому (`True`), но ссылки разные (`False`).
5. **`using`:**
   - `using var` для класса `IssueLog` (реализует `IDisposable`);
   - `using static System.Math` — вызов `Sqrt()` без имени класса;
   - `using MyDevice = SmartHome.SmartLamp` — псевдоним типа.

## Отличия C# от C++ в этой работе

| Аспект | C++ | C# |
|---|---|---|
| Абстрактный метод | `virtual ... = 0` | `abstract` |
| Переопределение | `override` | `override` |
| Вызов базы | `BaseDevice::Describe()` | `base.Describe()` |
| Конструктор базы | Список инициализации | `: base(...)` |
| Запрет наследования | `final` (класс) | `sealed` (класс) |
| Виртуальный деструктор | Обязателен | Нет деструкторов (есть GC) |
| Поверхностная копия | Копирование по умолчанию | `MemberwiseClone()` |
| Глубокая копия | Конструктор копирования / `Clone()` | Конструктор копирования |
| Сравнение по содержимому | Перегрузка `==` | `Equals()` + `GetHashCode()` |
